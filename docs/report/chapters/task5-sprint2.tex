\section{Task 5 -- Triển khai Sprint 2, CI/CD và Delivery}\label{sec:sprint2}

\textbf{Sprint Goal:} hoàn thành luồng end-to-end menu $\rightarrow$ giỏ $\rightarrow$ đăng nhập $\rightarrow$ đặt đơn
$\rightarrow$ thanh toán $\rightarrow$ theo dõi đơn, tự động đóng gói và triển khai production. Sprint gồm các mục
PB-10 $\rightarrow$ PB-19 và PB-25. Chi tiết: \code{docs/process/sprint-2.md}.

\subsection{Task 5.1 -- Hoàn thiện MVP}

\begin{itemize}
  \item \textbf{Xác thực:} \code{POST /auth/register}, \code{POST /auth/login}; mật khẩu băm bcrypt (cost 12), JWT HS256 hết hạn
        60 phút, \code{RolesGuard} cho ba vai trò CUSTOMER, STAFF, MANAGER (MANAGER làm được mọi việc của STAFF).
  \item \textbf{Đặt đơn:} \code{POST /orders} tính lại giá ở server (BR-05), chụp snapshot tên và đơn giá (BR-06), trừ kho bằng
        \code{UPDATE ... WHERE stock >= qty} trong một transaction nên tồn kho không bao giờ âm kể cả khi đặt đồng thời (BR-07).
        Đơn giữ kho 15 phút; tác vụ định kỳ hủy đơn quá hạn và hoàn kho (BR-08).
  \item \textbf{Thanh toán:} \code{POST /payments} với header \code{Idempotency-Key}; Payment Service mô phỏng quyết định kết quả theo số thẻ thử.
        Trả 201 khi thành công, 402 khi bị từ chối, 202 khi chậm. Thất bại lần thứ 3 hủy đơn và hoàn kho (BR-09).
        Cơ sở dữ liệu chỉ lưu bốn số cuối của thẻ (BR-18).
  \item \textbf{Giao diện:} chi tiết sản phẩm, giỏ hàng, đăng ký/đăng nhập, checkout, xác nhận và lịch sử đơn, màn nhân viên, PWA.
\end{itemize}

\subsection{Task 5.3 -- Continuous Delivery}

Workflow \code{cd.yml}: \emph{quality gate} (lint, typecheck, test, build) $\rightarrow$ build image API với tag commit SHA và
\code{vX.Y.Z} $\rightarrow$ push GHCR $\rightarrow$ deploy API (Render deploy hook) và web (Vercel CLI) $\rightarrow$ smoke test
(\code{/health}, \code{/api/v1/products}, trang chủ) $\rightarrow$ tự rollback về SHA trước nếu lỗi. Migration chạy khi container khởi động
(\code{prisma migrate deploy}); lỗi migration thì bản cũ vẫn phục vụ. Secret chỉ nằm trong GitHub Secrets và được che khỏi log.
