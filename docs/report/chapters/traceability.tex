\section{Ma trận truy vết}\label{sec:trace}

Ma trận truy vết (\code{docs/traceability-matrix.md}, phiên bản 0.2 sau Task 2) liên kết mỗi yêu cầu với use-case/user
story, sơ đồ thiết kế, API và test. Cột Code/API hiện là hợp đồng API từ SRS; cột Test là mã test dự kiến. Hai cột này
được cập nhật thành đường dẫn mã nguồn và kết quả test thật ở Task 4--5.

Quy ước mã test: \code{UNIT} unit test; \code{API} integration test một endpoint; \code{INT} integration test nhiều
bước; \code{E2E} end-to-end; \code{SMOKE} smoke test sau triển khai.
