\section{Ma trận truy vết}\label{sec:trace}

Ma trận truy vết (\code{docs/traceability-matrix.md}, phiên bản 0.4 sau Task 4) liên kết mỗi yêu cầu với use-case/user
story, sơ đồ thiết kế, API và test. Dòng có dấu (*) đã hiện thực ở Sprint 1: cột Code/API trỏ tới mã nguồn, cột
Test là test đang chạy trong CI. Các dòng khác là hợp đồng API từ SRS và mã test dự kiến, cập nhật ở Task 5.

Quy ước mã test: \code{UNIT} unit test; \code{API} integration test một endpoint; \code{INT} integration test nhiều
bước; \code{E2E} end-to-end; \code{SMOKE} smoke test sau triển khai.
